# 3단계 학습 계획 (2세트, 프롬프트 v2)

사용자 요청에 따라 2026-10-27 01:00 전에 끝나는 만큼만 학습한다. 정책 하나는 2,000회 반복에 약 29분이 걸린다(A1 측정값).

| 구분 | 명령 | 비고 |
| --- | --- | --- |
| 학습 완료 | A1 | 17:49~18:18 |
| 학습 (이 순서) | A4, B3, B9, B10, A10, A5, A8, A3, A6, B1, B2, B6, B8 | 2단계 2점을 먼저, 1점을 뒤에 두었다. B8은 Cautious와 값이 비슷하여 마지막에 두었다 |
| 기존 정책 재사용 | A2 = sneak_c (Cautious), A9 = sway (Swaying), B4 = tired (Tired), base | 생성된 파라미터가 walk_behaviors에서 학습한 정책과 완전히 같다 (같은 시드, 같은 반복 횟수) |
| 이번에 학습하지 않음 | A7, B7 | 2단계 0점: 파라미터가 명령과 반대 |
| 이번에 학습하지 않음 | B5 | Energetic과 거의 같은 값 (m_arm 1.5 대 1.8, 팔꿈치 굴곡 40° 대 45°) |

실행: `run_style_walk.py --resume <이 폴더> --iters 2000 --only <위 순서> --deadline 01:00 --est-min 32`. 마감 전에 끝낼 수 없는 학습은 시작하지 않으며, 01:00에는 systemd 타이머가 실행기를 멈춘다. 처음 실행에서 A2 학습이 4분 진행된 상태로 중단되었고, 그 폴더는 sneak_c 연결로 바꾸었다.
