# 3단계 학습 계획 (2세트, 프롬프트 v3)

2세트는 v3를 고칠 때 본 개발용 세트이다. 여기서는 v2의 3단계 실패 원인(값이 작아 보이지 않음, 함께 바꿀 값이 빠짐)을 고친 규칙이 실제 동작에서도 효과가 있는지를, 같은 명령의 v2 정책과 나란히 비교하여 확인한다. 사용자 요청에 따라 2026-10-27 24:00 전에 영상과 측정까지 끝나도록 학습 마감은 23:25로 둔다(정책 하나 약 29분).

| 구분 | 명령 | 비고 |
| --- | --- | --- |
| 학습 (이 순서) | A10, B9, A8, B7 | A10은 팔을 들 때 m_arm 0.3 규칙(v2 3단계 1점), B9는 고개 25°와 1.32배 속도, A8은 보폭 1.4배(둘 다 v2 3단계 1점, 값이 작음), B7은 v2에서 2단계 0점이라 학습하지 않은 명령 |
| 기존 정책 재사용 | base, A2 = sneak_c, A4 = v2 A4, B4 = tired, B6 = v2 B6, B10 = v2 B10 | v3의 값이 이미 학습한 정책과 완전히 같다 |
| 비교용 연결 | A10_v2, B9_v2, A8_v2, B1_v2 | v2 정책 (20261026_162305_v2_set2) |
| 시간 때문에 뺌 | A7, B1 | 3세트에는 v3 결과만 있어 비교 기준이 없으므로, 이 두 정책의 학습 시간에 v2를 3세트로 실행한다 |
| 이번에 학습하지 않음 | A1, A6 | v3에서도 2단계 1점이고 값이 거의 그대로라 3단계 결과가 달라지지 않을 것으로 봄 |
| 이번에 학습하지 않음 | A3, A5, A9, B2, B3, B5, B8 | v2와 값의 차이가 작거나(A3, A5, B2, B3, B8) v2에서 이미 2점인 스타일 (A9, B5) |

실행: `run_style_walk.py --resume <이 폴더> --iters 2000 --only A10,B9,A8,B7 --deadline 23:25 --est-min 32`, 이어서 `film_all.sh`, 그다음 v2(커밋 51ff297)를 3세트로 실행한다. 처음에는 A7과 B1까지 넣어 20:49에 시작하였으나, 3세트의 v3 결과를 본 뒤 20:52에 멈추고 두 정책을 빼서 다시 시작하였다(A10 학습 3분이 버려짐).
