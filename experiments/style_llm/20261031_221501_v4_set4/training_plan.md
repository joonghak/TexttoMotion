# 학습 계획 (4세트, 프롬프트 v4)

v4가 고른 동작과 값으로 걷기 외 동작의 정책을 학습한다. 비교 기준인 각 동작의 기본 정책과 이미 학습한 조합이 모두 1,500회 반복으로 학습되었으므로(2026-10-07, 10-08), 이번에도 1,500회로 맞춘다. 학습은 01:30까지 시작할 수 있는 것만 한다.

| 구분 | 명령 | 비고 |
| --- | --- | --- |
| 학습 (이 순서) | B1, B2, B3, B4, B5, B6 | 학습한 적 없는 스타일과 동작의 조합 |
| 이어서 학습 | A4, A2, A10, A6 | A4는 팔 흔들기를 0.3으로 낮춘 점프(Python 규칙), A2는 범위 최댓값(s 2, n 1.5)의 달리기, A10과 A6은 달리기의 박자 1.2배와 0.75배 |
| 기존 정책 재사용 | A1 = run/lean, A3 = jump/s1_25, A5 = kick/base, A7 = spinkick/base, A8 = run/crouch, A9 = run/sway2 | 값과 참조 모션이 이미 학습한 정책과 같다 |
| 각 동작의 기본 | base_run, base_jump, base_kick, base_spinkick | 20261007_144917_<동작>/base |
| 학습하지 않음 | W1, W2 | 걷기 명령은 동작 선택만 확인 |

실행: `run_style_walk.py --resume <이 폴더> --iters 1500 --only B1,B2,B3,B4,B5,B6,A4,A2,A10,A6 --deadline 01:30 --est-min 24`, 이어서 `film_all.sh`(동작마다 그룹 영상과 측정, 정책마다 비스듬한 단독 영상).
