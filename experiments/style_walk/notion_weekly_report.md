# 주간 보고: 레퍼런스는 고정, 보상 수식의 숫자만 바꿔 걷기 조절하기

## 지난주 할 일

- 레퍼런스 모션을 고치는 방식(방향 회전, 재생 속도 변경)은 우리 방향이 아니라는 피드백.
- 레퍼런스(`humanoid_walk.pkl`)는 그대로 두고, 보상 수식만 바꿔서 걷기를 조절하기.

## 이번주 한 일

### 결론

- 수식의 틀은 고정하고 **배율 숫자 4개**(팔 `a`, 발 `f`, 상체 `u`, 속도 `s`)만 바꿔서 걷기를 바꿀 수 있었다.
- **속도**: 0.75배 / 1.25배 명령에 실제 속도가 0.95 / 1.57 m/s (명령 0.94 / 1.57). 속도 추종 오차 1% 미만, 성공률 98.7~99.7%.
- **힘있게**: 팔 흔들기는 목표의 93~102%, 상체 기울기는 목표와 0.2° 이내로 단계적으로 바뀜. 발 들기는 왼발만 목표에 도달하고 오른발은 65~80%.
- 최종 목표는 LLM → 수식. 지금 단계는 LLM → 수식의 숫자(배율)이고, 그 숫자가 동작을 안정적으로 바꾸는지를 확인한 것.

### 1. 수식: 기존(DeepMimic)과 우리가 바꾼 것

기호:

- q, q̇: 관절 각도와 각속도. x, R, v, ω: 골반의 위치, 방향, 속도, 각속도. p_k: 머리·양손·양발의 위치. h: 발 높이. φ: 상체가 기운 각도.
- 모자(^)가 붙으면 레퍼런스 값. q̄: 그 관절의 걸음 한 주기 평균. x₀: 출발 위치(x̂₀는 그때의 레퍼런스 위치). g: 발이 바닥에 닿았을 때의 높이. c_j: 관절 가중치(몸통·허벅지 1.0, 머리·위팔·정강이 0.6, 아래팔·발 0.4, 손 0).
- 우리가 넣은 배율 4개: 팔 a, 발 f, 상체 u, 속도 s.

**기존 (DeepMimic, MimicKit 구현)**

$$
r = 0.5\,e^{-0.25\,E_1} + 0.1\,e^{-0.01\,E_2} + 0.15\,e^{-5\,E_3} + 0.1\,e^{-E_4} + 0.15\,e^{-10\,E_5}
$$

**우리**

$$
r = \frac{0.6\left(0.5\,e^{-0.25\,E_1} + 0.1\,e^{-0.01\,E_2} + 0.15\,e^{-5\,E_3} + 0.1\,e^{-E_4} + 0.15\,e^{-10\,E_5}\right) + 0.15\,\kappa(E_6) + 0.1\,\kappa(E_7)}{0.85}
$$

식의 모양과 숫자는 그대로 두고, 오차 E 안의 **목표**만 바꿨다. E6, E7은 새로 추가한 항. 아래에서 대괄호 [ ] 안이 바뀐 목표.

**E1 자세 (관절 각도)**

```
기존:  E1 = Σ_j c_j·(q_j − q̂_j)²
우리:  E1 = Σ_j c_j·(q_j − [q̄_j + m_j·(q̂_j − q̄_j)])²
```

- j: 관절 번호. 관절 12개(몸통, 머리, 양쪽 위팔·아래팔·허벅지·정강이·발)를 하나씩 계산해서 더한다(Σ_j).
- q_j: 지금 캐릭터의 관절 j 각도. q̂_j: 같은 시각 레퍼런스의 관절 j 각도. q̄_j: 레퍼런스에서 관절 j의 걸음 한 주기 평균 각도.
- c_j: 관절 j의 가중치(몸통·허벅지 1.0, 머리·위팔·정강이 0.6, 아래팔·발 0.4).
- m_j: 관절 j에 거는 배율. 관절마다 다르다. 팔 관절 4개(양쪽 위팔·아래팔)는 a, 허벅지 2개는 s, 나머지 6개는 1.
- 뜻: 기존은 "레퍼런스 각도와의 차이". 우리는 "평균에서 벗어난 만큼을 m배 한 각도와의 차이". m = 1인 관절은 대괄호가 q̂_j가 되어 기존과 같다.
- 예: 팔의 평균이 10°, 지금 레퍼런스가 30°(평균에서 +20°), a = 1.6이면 목표는 10 + 1.6×20 = 42°.

**E2 관절 속도**

```
기존:  E2 = Σ_j c_j·(q̇_j − q̂̇_j)²
우리:  E2 = Σ_j c_j·(q̇_j − m_j·q̂̇_j)²
```

- q̇_j: 캐릭터의 관절 j가 도는 속도. q̂̇_j: 레퍼런스의 관절 j가 도는 속도. m_j, c_j는 E1과 같다.
- 뜻: 각도 폭을 m배로 키웠으니 도는 속도 목표도 m배. 팔은 a배, 허벅지는 s배, 나머지는 그대로.

**E3 골반 위치와 방향**

```
기존:  E3 = (x − x̂)² + 0.1·(R − R̂)²
우리:  E3 = (x − [x₀ + s·(x̂ − x̂₀)])² + 0.1·(R − R̂)²
```

- x: 캐릭터의 골반 위치. x̂: 레퍼런스의 골반 위치. R, R̂: 캐릭터와 레퍼런스의 골반 방향.
- x₀: 에피소드 시작 때의 골반 위치. x̂₀: 그때의 레퍼런스 골반 위치(시작 순간에는 둘이 같다).
- (x̂ − x̂₀): 시작 후 레퍼런스가 이동한 거리. 대괄호는 "시작점 + s × 그 거리", 즉 레퍼런스보다 s배 멀리 간 지점.
- s는 앞뒤·좌우에만 곱한다. 높이와 방향 목표는 레퍼런스 그대로.
- 예: 2초 뒤 레퍼런스가 2.5 m 갔고 s = 1.25면 목표는 3.1 m 지점.

**E4 골반 속도**

```
기존:  E4 = (v − v̂)² + 0.1·(ω − ω̂)²
우리:  E4 = (v − s·v̂)² + 0.1·(ω − ω̂)²
```

- v, v̂: 캐릭터와 레퍼런스의 골반 이동 속도. ω, ω̂: 골반이 도는 속도.
- 뜻: 이동 속도 목표가 레퍼런스의 s배. 도는 속도 목표는 그대로.

**E5 끝점 (머리·손·발 위치)**

```
기존:  E5 = Σ_k ((p_k − x) − (p̂_k − x̂))²
우리:  E5 = Σ_k ((p_k − x) − D_k)²
```

- k: 부위 번호. 머리, 오른손, 왼손, 오른발, 왼발 5개를 하나씩 계산해서 더한다.
- p_k: 캐릭터의 부위 k 위치. (p_k − x): 골반에서 본 그 부위의 위치. (p̂_k − x̂): 레퍼런스에서 골반에서 본 그 부위의 위치.
- D_k: 우리가 쓰는 목표 위치(골반 기준). 머리는 레퍼런스 그대로. 손은 E1에서 바뀐 팔 각도대로 팔을 뒀을 때 손이 오는 위치. 발은 레퍼런스 발 위치에서 앞뒤 거리를 s배 하고 높이를 E6의 목표 높이로 바꾼 위치.
- 뜻: 팔·다리 목표를 바꿨으니 손·발 위치 목표도 거기에 맞춘 것. 안 맞추면 이 항이 손발을 원래 위치로 되돌린다.

**E6 발 높이 (추가)**

```
기존:  없음
우리:  E6 = Σ_양발 (h − [g + f·(ĥ − g)])²
```

- h: 캐릭터의 발 높이. ĥ: 같은 시각 레퍼런스의 발 높이. 오른발, 왼발을 각각 계산해서 더한다.
- g: 레퍼런스에서 그 발이 가장 낮을 때의 높이, 즉 땅에 닿아 있을 때 높이(약 4 cm).
- (ĥ − g): 레퍼런스 발이 바닥에서 뜬 높이. 대괄호는 "바닥 + f × 뜬 높이".
- 예: 레퍼런스 발이 10 cm 뜬 순간 f = 1.4면 목표는 14 cm 뜬 높이.

**E7 상체 기울기 (추가)**

```
기존:  없음
우리:  E7 = (φ − u·φ̂)²
```

- φ: 캐릭터의 상체가 기운 각도. 골반에서 머리로 이은 선이 수직선에서 벗어난 각도다. φ̂: 같은 시각 레퍼런스의 그 각도.
- u: 상체 배율. 1보다 작으면 더 꼿꼿하게.
- 예: 레퍼런스가 3° 기운 순간 u = 0.6이면 목표는 1.8°.

$$
\kappa(E) = \tfrac{1}{3}\left[e^{-20E} + e^{-\sqrt{20k}\,E} + e^{-kE}\right]
$$

- 배율이 1이면 대괄호는 레퍼런스 값과 같아져서 기존 식이 된다.
- 관절 각도의 뺄셈은 실제로는 3차원 회전 사이의 각도로 계산한다. "평균 + m·(레퍼런스 − 평균)"도 회전에서 같은 뜻(평균 자세에서 벗어난 만큼을 m배)으로 계산한다.
- κ는 추가 항 전용 점수. 민감도 세 개(20, √(20k), k)의 평균이고, k는 "레퍼런스를 그대로 따를 때의 평균 오차"의 역수로 자동 결정된다.
- 가중치: 기존 다섯 항 묶음에 0.6, 발 높이 0.15, 상체 0.1을 주고 합 0.85로 나눈다.
- 속도 s의 골반 목표는 보상뿐 아니라 종료 조건(목표에서 1 m 이탈)과 관측(다음 3스텝 목표)에도 같이 적용한다. 속도 항만 따로 더하면 기존 E3와 싸우고, 계산상 1.25배면 약 3초 뒤 1 m 벗어나 종료된다.

실험별 설정:

- 기본 걷기: 기존 식 그대로.
- 힘있게: 우리 식 전체, s = 1. (a, f, u) = (1.3, 1.2, 0.8) / (1.6, 1.4, 0.6) / (2.0, 1.7, 0.4).
- 속도: a = f = u = 1이고 E6, E7 없음(기존 다섯 항에 s만 적용). s = 0.75 / 1.25.

### 수식의 출처와 비슷한 선행 식

- 기존 식(E1~E5): MimicKit 코드와 설정 파일 그대로. 원 논문은 DeepMimic(Peng 외, 2018)이고 논문 식은 항 4개(자세 0.65, 속도 0.1, 손발 끝 0.15, 무게중심 0.1)로 구성이 다름.
- 우리가 바꾼 부분: 참고한 논문 없이 실험하며 설계. 아래는 사후에 찾은 비슷한 식.

| 우리 것 | 비슷한 선행 식 | 출처 | 차이 |
|---|---|---|---|
| 전체 구조: 추종 0.6 + 추가 항 | r = 0.7·r_모방 + 0.3·r_과제 | DeepMimic 논문 | 과제 항이 레퍼런스와 무관한 목표(방향, 타격) |
| 관절 목표 Q = q̄ + m·(q̂ − q̄) | G₀ = G_DC + Σ g_k·L_k (관절 각도를 주파수 대역으로 나눠 대역별 게인). 게인이 모두 같으면 Q와 같은 식 | Bruderlin & Williams 1995, Motion Signal Processing | 모션 자체를 고쳐 재생하는 편집 기법. 우리는 그 값을 물리 시뮬레이션 보상의 목표로 사용 |
| 발 높이 E6 = Σ(h − H)² | Σ_발 (h_발 − h_cmd)²·C_swing, 가중치 −0.6 | Walk These Ways (Margolis & Agrawal 2022) | 명령값을 직접 줌(레퍼런스 없음), 벌점으로 더함 |
| 상체 E7 = (φ − u·φ̂)² | (φ − φ_cmd)², 가중치 −0.1 | 같은 논문 | 위와 같음 |
| 속도 s (골반 경로 s배) | r_과제 = exp[−2.5·max(0, v* − v·d*)²] / exp{−\|v − v_cmd\|²/σ} / 레퍼런스를 시간 축으로 늘린 버전을 모방 | DeepMimic 논문 / Walk These Ways / Xie 외 2018 (Cassie) | 골반 경로를 공간적으로 s배 늘리고 다리 목표도 s배 하는 식은 찾지 못함 |
| κ (민감도 3개 평균) | 16·(1 − tanh(d/0.3)) + 5·(1 − tanh(d/0.05)): 같은 오차를 넓은 커널과 좁은 커널로 채점해 더함 | Isaac Lab 기본 과제(lift, reach, navigation) | 커널 모양(tanh), 개수(2개). k 자동 결정은 우리 것 |
| LLM → 정해진 보상 항의 숫자 | LLM이 문장을 미리 정의된 보상 함수의 파라미터로 번역 | Language to Rewards (Yu 외 2023) | 최적화가 MPC, 레퍼런스 모션 없음 |

- 비슷한 식을 찾지 못한 것: k 자동 결정 규칙, 가중치 0.6 / 0.15 / 0.1, 발 높이를 바닥 기준으로 배율하는 식, 속도 목표를 종료 조건·관측에 같이 적용하는 것.

|---|---|---|
| 속도 추종 오차 | 명령대로 됐나 | 명령 속도와 실제 속도의 차 ÷ 명령 속도 |
| 성공률 | 안정적인가 | 무작위 시점에서 시작한 10초 에피소드 약 385개 중 안 넘어진 비율 |
| 좌우 차이 | 눈에 띄는 결함이 없나 | 오른발·왼발 들기 높이의 차 ÷ 평균 (보행 분석의 대칭 지수) |

$$
e_{\text{speed}} = \frac{|v_{\text{actual}} - v_{\text{cmd}}|}{v_{\text{cmd}}}, \qquad \text{SI} = \frac{|X_R - X_L|}{0.5\,(X_R + X_L)} \times 100\%
$$

- 속도는 문장이 가리키는 양을 시뮬레이션에서 직접 잴 수 있어서 그대로 추종 지표가 된다. 실제 속도는 골반이 간 거리 ÷ 시간으로, 보상 수식과 무관하게 잰다.
- "힘있게"처럼 가리키는 물리량이 하나로 정해지지 않는 명령은, 우리 수식을 모르는 판정자(사람 등)가 문장과 동작을 보고 판정해야 한다. 아직 하지 않음.
- 출처: 속도 추종 오차는 속도 명령을 따르는 보행 로봇 연구, 성공률은 PHC·MaskedMimic 같은 모방 제어 연구, 대칭 지수는 보행 분석(Robinson, 1987)에서 쓰는 지표.
- 진단용으로 "수식이 준 목표 자세 대비 관절 위치 오차"도 잰다. 명령 추종 지표는 아니고, 수식의 목표들이 서로 모순되는지 보는 용도(골반만 3.0 cm, 다리까지 2.6 cm, 기본 2.4 cm).

### 5. 알게 된 것

- **학습량이 품질을 크게 좌우한다.** 기본 걷기 기준 1000회 → 2000회에서 디딤 무릎 28.7° → 18.5°(레퍼런스 약 18°), 팔 관절 오차 5~8° → 1~2°, 발 들기 레퍼런스의 59~69% → 82~84%.
- **목표는 DeepMimic 항 안에 넣는 게 안정적이다.** 팔을 별도 추가 항으로 뒀을 때는 팔이 목표에서 35~45° 벗어났다.
- **버린 시도**: 골반 높이 유지 항(오른발이 더 안 들림), 발이 0.1초 늦어도 되게 허용(양발 모두 낮아짐).

### 6. 남은 문제

- 오른발만 덜 드는 문제. 힘있게(1000회)와 천천히(2000회) 모두에서 나타남. 기본 걷기 정책도 오른발을 레퍼런스보다 늦게 떼는 것까지만 확인.
- 팔 배율은 수학적으로 "늘린 레퍼런스의 팔을 추적"하는 것과 같다. 레퍼런스 파일과 관측은 그대로지만, 레퍼런스 수정이 아니냐는 질문이 나올 수 있음.
- 속도는 0.75~1.25배만 확인. 박자를 고정했기 때문에 사람이 실제로 빨리 걷는 방식(박자도 빨라짐)과는 다르다.
- 문장과는 아직 연결되지 않음. 지금은 배율을 직접 넣는다.
