# 여러 동작에 공통으로 쓰는 수식 영상 (2026-11-01 ~ 11-03)

같은 스타일 파라미터 값을 이전 수식(2026-11-01까지)과 새 수식(2026-11-03에 고정, `experiments/style_walk/FORMULA.md`)으로 학습하여, 그 동작의 기본 정책 옆에 세워 찍었다. 모든 정책은 고른 참조 모션을 그대로 모방하며, 기본 정책과 다른 것은 보상의 목표와 항뿐이다. 다른 동작은 1,500회, 걷기는 2,000회 반복 학습하였다. 학습 폴더는 `experiments/style_walk/20261101_225050_general_formula`이고, 측정값과 판정은 그 폴더의 plan.md에 있다. 영상에는 글자를 넣지 않았다.

## 색과 위치

그룹 영상에서 파랑은 항상 그 동작의 기본 정책(참조 모션을 그대로 모방)이다. 느린 캐릭터가 왼쪽(뒤)에서, 빠른 캐릭터가 오른쪽(앞)에서 출발하고, 이동하는 동안 속도 차이만큼 벌어진다. 속도가 같은 캐릭터는 아래 표의 색 순서대로 왼쪽부터 선다.

| 영상 | 파랑 | 초록 | 빨강 | 보라 | 출발할 때 왼쪽부터 |
| --- | --- | --- | --- | --- | --- |
| group_walk_tired, group_walk_zombie, group_walk_sneak | 기본 보행 | 이전 수식 | 새 수식 | - | 초록, 빨강, 파랑 (파랑이 점점 멀어짐) |
| group_run_tired | 기본 달리기 | 이전 수식 | 새 수식 | - | 초록, 빨강, 파랑 (파랑이 점점 멀어짐) |
| group_run_zombie | 기본 달리기 | 이전 수식 | 새 수식, 팔 기준 없음 | 최종 수식 | 초록, 빨강, 보라, 파랑 (파랑이 점점 멀어짐) |
| group_jump_head, group_jump_arms | 기본 점프 | 이전 수식 | 새 수식 | - | 파랑, 초록, 빨강 (간격 그대로) |
| group_jump_low | 기본 점프 | 이전 수식 | 새 수식 | - | 파랑, 초록, 빨강 (초록과 빨강이 조금씩 앞섬) |
| group_kick_back | 기본 발차기 | 이전 수식 | 새 수식 | 새 수식, 자세 항 가중치 0.4 | 파랑, 초록, 빨강, 보라 |
| group_spin_tired | 기본 돌려차기 | - | 새 수식 | - | 빨강, 파랑 (파랑이 조금씩 앞섬) |

새 수식은 고정한 수식과 같다. 팔 기준(팔의 자세 오프셋을 걷기의 팔 자세 기준으로 재는 것)은 팔 자세 오프셋이 있을 때만 작동하므로, 좀비 달리기의 빨강만 고정한 수식과 다르다.

## 명령과 값

값은 기본값에서 바뀐 것만 적었다. s는 공간 배율, n은 시간 배율, c는 무릎 굽힘 각(°), m은 진폭 배율이다. 상체와 고개 기울기는 앞(+)과 뒤(−)로 기운 각도이고, 어깨 굴곡은 팔을 앞으로 든 각도, 어깨 외전은 팔을 옆으로 든 각도, 팔꿈치 굴곡과 신전은 팔꿈치를 굽히거나 편 각도이다. 이전 수식과 새 수식은 같은 값이다(group_jump_arms만 다름).

| 영상 | 명령 | 값 | 볼 곳 |
| --- | --- | --- | --- |
| group_walk_tired | 지쳐서 터벅터벅 걸어 (Tired) | s 0.8, n 0.75, m_arm 0.4, m_knee 0.8, 상체 앞으로 15°, 고개 25° | 초록과 빨강이 같은 모습으로 상체를 숙이고 고개를 떨군 채 느리게 걷는다. 빨강의 고개가 조금 더 숙여져 있다 |
| group_walk_zombie | 좀비처럼 걸어 | s 0.85, n 0.6, m_arm 0.3, m_torso 5, 상체 앞으로 10°, 어깨 굴곡 85°, 팔꿈치 신전 30° | 초록과 빨강이 같다. 두 팔을 앞으로 뻗고 상체를 좌우로 흔들며 느리게 걷는다 |
| group_walk_sneak | 살금살금 걸어 (Sneaky) | s 0.8, n 0.6, c 20, m_arm 0.3, m_knee 0.7, 상체 앞으로 20°, 어깨 굴곡 20°, 팔꿈치 굴곡 40° | 초록과 빨강이 같다. 무릎을 굽혀 낮게 걷고 팔을 몸 앞에 모은다 |
| group_run_tired | 지쳐서 터벅터벅 달려 (4세트 B1) | 지쳐서 터벅터벅 걸어와 같은 값 | 초록과 빨강 모두 상체를 크게 숙이고 고개를 떨군 채 느리게 달린다. 빨강이 조금 더 숙였다 |
| group_run_zombie | 좀비처럼 팔을 앞으로 뻗고 달려 (4세트 B2) | 좀비처럼 걸어와 같은 값 | 초록은 상체가 크게 흔들리고 정면 사진에서 팔이 비대칭이다. 빨강은 흔들림이 줄었으나 팔꿈치를 굽힌 채 팔이 바깥으로 벌어진다. 보라는 좀비 걸음처럼 두 팔을 곧게 앞으로 뻗지만, 발을 낮게 끌며 휘청이듯 달린다 |
| group_jump_head | 고개를 푹 숙이고 점프해 (4세트 B3) | 고개 25° | 빨강이 준비 자세와 착지 때 고개를 더 숙인다. 초록은 기본 점프와 거의 같다 |
| group_jump_low | 무릎을 굽히고 낮게 점프해 (4세트 B6) | n 1.25, c 20 | 초록과 빨강이 같다. 기본보다 깊이 앉았다가 낮고 빠르게 뛴다 |
| group_jump_arms | 양팔을 쫙 펴고 점프해 (4세트 A4) | 빨강: 어깨 외전 80°, m_arm 0.3. 초록: 어깨 외전 80°(2026-10-08에 학습한 정책) | 빨강은 점프 내내 팔을 어깨 높이로 옆으로 편다. 초록은 팔이 점프의 팔 흔들기를 따라 앞뒤로 움직인다. 빨강의 점프가 조금 낮다 |

| group_spin_tired | 지쳐서 돌려차기 | 지쳐서 터벅터벅 걸어와 같은 값 | 빨강이 상체를 숙이고 고개를 떨군 채 느리게 돌아 찬다. 차는 높이는 기본과 비슷하다. 박자가 달라 근접 사진의 같은 칸이 같은 동작 순간은 아니다 |

## 근접 사진의 이름

근접 사진의 줄 이름은 학습 폴더의 정책 이름이다. base로 시작하는 것은 기본 정책, o_로 시작하는 것은 이전 수식, n_로 시작하는 것은 새 수식이다. n3_run_B2와 n2_jump_A4는 팔 기준까지 쓴 최종 수식 정책이고, n_kick_B5_w4는 자세 항 가중치를 0.4로 한 정책이다. 이전 수식 정책은 걷기가 `20261015_151030_walk_behaviors`, 달리기와 점프와 발차기가 `experiments/style_llm/20261031_221501_v4_set4`, 팔 벌린 점프가 `20261008_231751_jump/arms_out`에서 학습한 것을 그대로 쓴 것이다.
