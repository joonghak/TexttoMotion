# 프롬프트 v3 비교 영상 (2세트, 2026-10-27)

v2에서 3단계 점수가 낮았던 2세트 명령을 v3가 정한 값으로 다시 학습하여, 같은 명령의 v2 정책과 기본 보행 옆에 세워 찍었다. 모든 정책은 같은 보행 참조 모션(humanoid_walk)을 모방하도록 2,000회 반복 학습하였고, 바뀐 것은 LLM이 정한 비교 목표뿐이다. 영상에는 글자를 넣지 않았다. 학습 폴더는 `experiments/style_llm/20261027_192233_v3_set2`이다.

## 파일

| 파일 | 내용 | 카메라 | 길이 | 볼 곳 |
| --- | --- | --- | --- | --- |
| pair_A10, pair_B9, pair_A8 (.mp4 / .gif) | 기본 보행, v2 정책, v3 정책 | 측면, 캐릭터는 오른쪽으로 걸음 | 10초 | 같은 명령에서 v2와 v3의 차이 |
| pair_B7 (.mp4 / .gif) | 기본 보행, v3 정책 | 측면 | 10초 | v2에서는 학습하지 않은 명령 |
| solo_<ID>_v3 (.mp4 / .gif) | v3 정책 하나 | 진행 방향에서 40° 비스듬히 | 약 4초 | 팔, 상체, 보폭의 모양 (단독 영상의 색은 의미 없음) |

같은 명령의 v2 단독 영상은 `../style_llm_set2/solo_<ID>.mp4`에 있다.

## 색과 위치

| 색 | 정책 |
| --- | --- |
| 파랑 | 기본 보행 |
| 초록 | v2가 정한 값으로 학습한 정책 |
| 빨강 | v3가 정한 값으로 학습한 정책 |

비교 영상에서는 빠른 캐릭터가 오른쪽(앞)에서 출발하고, 걷는 동안 속도 차이만큼 벌어진다.

| 영상 | 출발할 때 왼쪽부터 | 8초 무렵 왼쪽부터 |
| --- | --- | --- |
| pair_A10 | 초록, 빨강, 파랑 | 초록과 빨강(같은 속도), 멀리 파랑 |
| pair_B9 | 파랑, 초록, 빨강 | 파랑, 초록, 빨강 (빨강이 가장 빠름) |
| pair_A8 | 파랑, 초록, 빨강 | 파랑과 초록(거의 같은 속도), 멀리 빨강 |
| pair_B7 | 빨강, 파랑 | 빨강, 멀리 파랑 |

## 명령과 값

값은 기본값에서 바뀐 것만 적었다. s 보폭 배율, n 시간 배율, c 무릎 굽힘 각(°), m 진폭 배율, pitch는 앞(+)·뒤(−) 기울기(°), shoulder_flexion은 팔을 앞으로 든 각도, elbow_flexion은 팔꿈치 굽힘(°, −는 폄)이다. 3단계는 영상 판정(0~2점)이다.

| ID | 명령 | v2의 값 | v3의 값 | 3단계 v2 → v3 | 볼 곳 |
| --- | --- | --- | --- | --- | --- |
| A10 | 두 팔을 앞으로 나란히 뻗고 천천히 걸어 | n 0.6, shoulder_flexion 85, elbow_flexion −30 | n 0.6, m_arm 0.3, shoulder_flexion 85 | 1 → 1 | 초록은 팔이 위아래로 번갈아 흔들리고, 빨강은 팔이 함께 움직이지만 팔꿈치를 굽혀 아래팔이 들림 |
| B9 | 비를 맞으며 고개를 숙이고 서둘러 걸어 | s 1.1, n 1.1, head_pitch 20 | s 1.15, n 1.15, m_arm 1.5, head_pitch 25 | 1 → 1 | 빨강이 가장 빠르고 팔을 크게 흔듦. 고개 숙임은 둘 다 거의 보이지 않음 |
| A8 | 한 걸음 한 걸음 크게 내디디며 걸어 | s 1.2, n 0.85 | s 1.4 | 1 → 2 | 빨강의 보폭이 파랑과 초록보다 분명히 큼 |
| B7 | 고양이처럼 사뿐사뿐 걸어 | s 0.8, n 1.2, c 10, m_arm 1.5, m_knee 1.5 (2단계 0점, 학습하지 않음) | s 0.8, c 10, m_arm 0.4, m_torso 2, m_knee 0.8, torso_pitch 10, head_pitch −10 | - → 1 | 무릎을 굽히고 짧게 걸으며 발을 거의 한 줄로 디딤. 조용한 걸음이지만 낮은 자세 때문에 가벼운 걸음보다 살금살금 걷는 모습에 가까움 |
