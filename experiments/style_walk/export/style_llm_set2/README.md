## 명령과 LLM이 정한 값

값은 기본값에서 바뀐 것만 적었다. s 보폭 배율, n 시간 배율, c 무릎 굽힘 각(°), m 진폭 배율, pitch는 앞(+)·뒤(−) 기울기(°), shoulder_flexion은 팔을 앞으로 든 각도, elbow_flexion은 팔꿈치 굽힘(°, −는 폄)이다. 3단계는 영상 판정(0~2점)이다.

| ID | 명령 | LLM이 정한 값 | 3단계 | 볼 곳 |
| --- | --- | --- | --- | --- |
| A1 | 발소리가 나지 않게 몰래 걸어 | m_arm 0.3, m_torso 0 | 0 | 기본 보행과 거의 같음 (팔 흔들기만 작음) |
| A2 | 넘어지지 않게 한 발 한 발 신중하게 걸어 | n 0.5, c 15, m_arm 0.3, m_knee 0.8, torso_pitch 15, shoulder_flexion 20, elbow_flexion 40 | 2 | 무릎을 굽히고 팔을 앞에 모은 느린 걸음 (기존 Cautious 정책과 같은 값) |

| A4 | 허벅지를 높이 들면서 걸어 | c 15, m_knee 1.5 | 1 | 발이 높이 들리지만 허벅지보다 뒤꿈치를 차올리는 모양 |

| B2 | 우아하게 천천히 걸어 | n 0.75, c 10, m_torso 5, m_knee 0.8, torso_pitch 5 | 1 | 느리지만 무릎 굽힘과 상체 흔들림 때문에 우아해 보이지 않음 |
| B3 | 배가 아파서 배를 움켜쥐고 걸어 | m_arm 0.4, torso_pitch 10, head_pitch 20, elbow_flexion 45 | 2 | 팔뚝이 배 앞에 오고 고개를 숙임 |

| B10 | 1분에 140걸음 걷는 빠르기로 걸어 | n 1.2 | 2 | 측정 139.3걸음/분 (목표 140) |
