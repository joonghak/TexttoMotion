# 우리 정책과 100STYLE 비교 (2026-11-11)

GIF마다 화면이 넷이다. 왼쪽 파랑은 우리 정책(Isaac Lab에서 학습한 정책을 실행), 오른쪽 보라는 100STYLE 모션 캡처를 우리 캐릭터에 옮겨 학습 없이 그대로 재생한 것이다. 위는 옆에서, 아래는 정면(캐릭터가 카메라 쪽으로 걸어옴)이며, 카메라가 각 캐릭터를 따라간다. 걷기 시작 2초 뒤부터 7.8초이다. 아래 줄의 값은 학습한 정책을 따로 30초씩 기록하여 잰 지표이다.

우리 정책의 값은 10월에 사람이 직접 정한 것이고(LLM이 낸 값이 아님), 100STYLE을 쓰기 전에 정하였다. 모두 걷기 참조 모션 하나와 보상 수식으로 2,000회 학습하였다.

100STYLE을 옮긴 방법: 배우의 관절 회전을 우리 캐릭터의 같은 관절에 넣었다(두 골격 모두 T자세가 기준). 골반 경로는 다리 길이의 비(0.956)로 줄이고, 매 프레임 발이 땅에 닿도록 높이를 맞추었다. 배우가 촬영 공간을 돌며 걸어서 10초 구간에도 120~260°의 회전이 있으므로, 회전을 빼고 곧게 폈다. 옮긴 동작을 같은 지표로 재면 8개 가운데 7개가 원래 스타일에 1위, 좀비는 2위였다(유사도 0.88~0.98). 옮기는 과정에서 스타일이 거의 바뀌지 않는다.
