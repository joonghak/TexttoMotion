# 개선 확인 영상 (2026-11-16)

11-12 밤에 넣은 새 기능을 학습한 정책으로 확인한 영상이다. 모두 2,000회 학습, 같은 캐릭터와 같은 보상 수식이며, 참조 모션은 걷기 클립 그대로이다.

## one_sided_side.gif, one_sided_front.gif (한쪽 동작과 까치발)

다섯 캐릭터가 한 시뮬레이션에서 나란히 걷는다. 위 영상은 옆에서, 아래 영상은 정면에서 찍었다. 정면 영상에서 왼쪽부터 빨강, 초록, 노랑, 보라, 파랑 순서이고, 옆 영상에서는 느린 빨강이 가장 뒤(왼쪽)에 있다.

| 색 | 명령 | 값을 정한 쪽 | 값 |
| --- | --- | --- | --- |
| 파랑 | (기준) 기본 걷기 | - | 스타일 없음 |
| 초록 | 오른쪽 다리를 절뚝거리며 걸어 | gpt-5.6-terra, 프롬프트 v11 | 오른쪽 무릎 흔들림 0.4 |
| 노랑 | 왼손을 번쩍 들고 걸어 | gpt-5.6-terra, 프롬프트 v11 | 왼팔만 앞으로 85°, 왼팔 흔들기 0.3 |
| 빨강 | 무거운 가방을 왼쪽 어깨에 메고 걸어 | gpt-5.6-terra, 프롬프트 v11 | 상체 오른쪽 15°, 고개 오른쪽 12°, 왼팔 앞으로 45°, 왼쪽 팔꿈치 60°, 왼팔 흔들기 0.3, 보폭 0.85, 박자 0.8 |
| 보라 | (까치발 확인) | 사람이 정한 값 | 발끝 세우기 25° |

잰 값(캐릭터 4개 × 30초, 기본 걷기와의 차이): 초록은 오른쪽 무릎의 움직임 범위가 35° 줄고 왼쪽은 4°만 줄었다. 노랑은 왼손이 팔 길이의 0.97만큼 높고 오른손은 그대로이다. 빨강은 상체가 오른쪽으로 7°, 고개가 20° 기울고 왼손이 0.75만큼 높다. 보라는 디딘 발의 발뒤꿈치가 다리 길이의 0.06(약 5 cm) 들렸다. 다섯 모두 넘어지지 않았다.

## vs100style_limp_right.gif, vs100style_raised_left_arm.gif, vs100style_tiptoe.gif

왼쪽 파랑이 우리 정책(위 표의 초록, 노랑, 보라), 오른쪽 보라가 100STYLE 배우의 모션 캡처를 우리 캐릭터로 옮긴 것이다(LimpRight, RaisedLeftArm, Tiptoe). 위는 옆, 아래는 정면이다. 왼손 들기에서 배우는 팔을 옆으로 들고 우리 답은 앞으로 들었는데, 둘 다 "왼손을 든" 걸음이다.

## chain_run_then_jump.gif, chain_walk_then_kick.gif, chain_walk_then_spinkick.gif (동작 이어붙이기)

한 캐릭터가 연속 동작 하나를 처음부터 끝까지 한 번 한다(옆에서 찍음). 명령은 10세트, 동작 순서와 길이는 gpt-5.6-sol(프롬프트 v12)이 정하였고, 그 순서대로 MimicKit의 동작 클립을 이어 붙인 참조 모션(이음 0.5초)을 스타일 없이 학습하였다.

| 파일 (색) | 명령 | LLM이 정한 순서 | 확인 |
| --- | --- | --- | --- |
| chain_run_then_jump (초록) | 뛰어가다가 앞으로 크게 점프해 | 달리기 2.4초 → 점프 1.77초 (보폭 1.4배) | 달리기 1.2초, 점프 2.9초에 판정, 순서 맞음 |
| chain_walk_then_kick (노랑) | 걸어가다가 앞차기 한 번 해 | 걷기 3초 → 앞차기 1.53초 | 걷기 2.1초, 차기 3.2초, 순서 맞음 |
| chain_walk_then_spinkick (빨강) | 걷다가 돌려차기 해 | 걷기 3초 → 돌려차기 1.28초 | 걷기 1.6초, 차기와 돌기 3.2~3.6초, 순서 맞음 |

캐릭터 4개 × 30초 동안 연속 동작을 76번 반복하는 사이 끝까지 가지 못한(넘어진) 경우는 없었다. 같은 명령의 공개 T2M 모델 출력은 요청한 순서가 맞은 비율이 MoMask 7/24, T2M-GPT 1/24, MDM 6/24였다(10세트 연속 동작 8개 × 출력 3개).

## arms_up_look_weave_front.gif, arms_up_look_weave_side.gif (두 팔 머리 위로, 고개 돌리기, 갈지자 길)

정면 영상에서 왼쪽부터 초록, 노랑, 빨강, 파랑이다. 모두 사람이 정한 값으로 새 기능을 확인한 것이다.

| 색 | 확인한 것 | 값 | 잰 값 |
| --- | --- | --- | --- |
| 초록 | 두 팔을 머리 위로 V자로 | 어깨 옆으로 160°, 팔 흔들기 0.3 | 손이 기본 걷기보다 팔 길이의 1.78배 높음 |
| 노랑 | 고개를 오른쪽으로 | head_yaw 50° | 머리가 몸통보다 42° 오른쪽을 향함. 머리가 무늬 없는 공이라 영상에서는 거의 보이지 않는다 |
| 빨강 | 갈지자로 걷는 길 | weave 0.3 m (3초 주기) | 옆으로 흔들린 폭 0.36 m (기본 걷기 0.13 m). 요청한 폭(0.6 m)의 절반 정도만 따라가서 영상에서는 작게 보인다 |
| 파랑 | 기본 걷기 | - | - |

넷 모두 넘어지지 않았다.
